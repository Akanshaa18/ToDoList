# To-Do List App

A simple to-do list web app built with vanilla HTML, CSS, and JavaScript.

Submitted as a minor project to fulfill a semester requirement during my undergraduate studies (2019).

---

## About

This was an early project built to demonstrate fundamental web development skills. The app allows users to add, complete, and delete tasks. It is nothing fancy, but a solid exercise in DOM manipulation and basic UI design.

## Tech Stack

- HTML
- CSS
- JavaScript (vanilla)

## Features

- Add new tasks
- Mark tasks as complete
- Delete tasks

## Context

This project was submitted as part of a minor project requirement in one of my undergraduate semesters. It reflects where I was in my learning journey at the time (kept it here for portfolio completeness).
